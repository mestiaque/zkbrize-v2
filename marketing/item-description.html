Connect ZKTeco attendance devices to your ERP — in minutes

AttendBridge collects punches from your ZKTeco fingerprint, face and card devices in real time, sends them to your ERP, HRM or payroll system through a simple REST API, and keeps the employee list on every device in sync. It runs on any Windows or Linux PC in your office, installs with one command and is set up entirely in the browser.

Works with any ERP in any language — Laravel, CodeIgniter, Django, ASP.NET, Node.js or your own system. Your ERP only needs three small JSON endpoints; a complete Laravel example is included.

Highlights

  • Real-time ADMS push — newer devices send every punch the moment it happens. No fixed device IP needed.
  • TCP/IP pull — older devices are read over port 4370, with comm-key login and automatic reconnects.
  • Two-way sync — employees from your ERP to the devices; attendance from the devices to your ERP.
  • Automatic schedules — sync employees and push attendance every few minutes, hourly or daily.
  • Attendance analytics dashboard — present, late and absent today, a 7-day trend, arrivals by hour, verification methods and punches per device. Updates live.
  • Nothing gets lost — punches are stored safely and re-sent until your ERP confirms them, even across restarts.
  • Browser setup wizard — no config files to edit. Create the admin account, connect the ERP and you are done.
  • Users, roles & permissions — custom roles with page- and button-level permissions, enforced on the server.
  • White-label — your app name, logo, colors and company name.
  • Runs as a service — one click installs it as a Windows service or a Linux systemd service that starts with the computer.
  • Works offline — everything runs on your local network; no cloud account, no external CDN.

Features

Devices

  • ADMS / Cloud Server push and TCP/IP (port 4370) devices, side by side
  • Device list with live status, model, serial number and firmware
  • Network ping test before connecting
  • Fetch historical attendance from devices, with a date range

Employees

  • Import from ERP, load from a device, add / edit / delete in the browser
  • Changes are written to connected devices; enrolled fingerprints and faces are kept
  • Export to CSV (ZKTeco desktop software) and user.dat (USB import)

Attendance

  • Live attendance table with filters: employee, date, device, check-in/out, method, source, sync status
  • Push to ERP on demand or on a schedule; duplicates are ignored automatically
  • Configurable work start time and grace period for late arrivals

Security

  • Hashed passwords, login rate limiting, server-side permission checks
  • Owner-only administration; emergency recovery login
  • Session-secured live updates

Requirements

  • Windows 10 / 11 / Server 2016+ or Linux (Ubuntu, Debian or any systemd distribution)
  • Node.js 20 or newer (free from nodejs.org)
  • ZKTeco devices with ADMS / Cloud Server support or TCP/IP port 4370
  • A PC or server on the same network as the devices (shared hosting is not supported)

Installation

  1. Install Node.js 20+
  2. Unzip the package and run npm install (or double-click start.bat on Windows)
  3. Open http://localhost:3000 and follow the setup wizard

Full offline documentation with screenshots is included: installation, device setup, the ERP API reference with a Laravel example, troubleshooting and FAQ.
